## 2. Introduction to FastAPI and REST APIs

### What is a REST API?
A **Representational State Transfer (REST)** Application Programming Interface (API) is an architectural style for building network-based services. REST relies on standard HTTP methods (`GET`, `POST`, `PUT`, `DELETE`) to manipulate stateless representations of resources (typically formatted as JSON).

### Why FastAPI?
**FastAPI** is a modern, high-performance web framework for building APIs with Python 3.8+ based on standard Python type hints. Key advantages include:
- **High Performance:** On par with NodeJS and Go, powered by Starlette and Uvicorn.
- **Data Validation:** Built-in automated request and response schema validation using **Pydantic v2**.
- **Interactive Documentation:** Automatic generation of OpenAPI (Swagger UI) and ReDoc documentation with zero extra configuration.
- **Developer Productivity:** Excellent editor autocompletion and type safety.

## 3. Important Terminology

| Term | Definition |
|---|---|
| **Endpoint / Route** | A specific URL path exposed by an API where requests are received (e.g., `/books`). |
| **HTTP Method** | The verb indicating the action to perform on a resource (`GET`, `POST`, `PUT`, `DELETE`). |
| **Payload / Request Body** | Data sent by a client to the server within an HTTP request (typically JSON). |
| **Response Body** | Data returned by the server to the client after processing the request. |
| **Pydantic Model** | A Python class defining data schema, types, and validation rules for payloads. |
| **Uvicorn** | A lightning-fast ASGI (Asynchronous Server Gateway Interface) web server implementation for Python. |
| **Swagger UI** | An interactive, web-based interface for exploring, testing, and visualizing REST API endpoints. |
| **Status Codes** | Three-digit integers standardized by HTTP protocols indicating the outcome of a request. |

## 4. Book Management System Scenario

The API manages a catalog of books. Each book resource consists of four attributes:
- `id` (*integer*): Unique auto-incremented identifier generated by the server.
- `title` (*string*): Title of the book (1 to 100 characters; whitespace trimmed).
- `author` (*string*): Author of the book (1 to 80 characters; whitespace trimmed).
- `publication_year` (*integer*): The publication year (bounded between 1450 and 2100).

The application is pre-seeded with two canonical books:
1. **The Alchemist** by Paulo Coelho (1988) — `id: 1`
2. **Wings of Fire** by A. P. J. Abdul Kalam (1999) — `id: 2`

|---|---|---|---|
| `GET` | `/` | API welcome greeting and status check | `200 OK` |
| `GET` | `/books` | Retrieve the list of all stored books | `200 OK` |

## 8. Explanation of the Implementation (`main.py`)

1. **Application Initialization:**
   The application is initialized with `FastAPI(...)` including metadata: `title="Book Management API"`, `description="A simple REST API built with FastAPI."`, and `version="1.0.0"`.

2. **Schema Modeling with Pydantic v2:**
   - `BookBase`: Defines validation constraints using `Field(...)` (`min_length`, `max_length`, `ge`, `le`). A `@field_validator` ensures titles and author names cannot be blank or contain solely spaces.
   - `BookCreate`: Subclasses `BookBase` for incoming payloads in `POST` and `PUT` requests.
   - `Book`: Inherits `BookBase` and adds the server-controlled `id: int` field.

3. **In-Memory Storage & Auto-Increment:**
   - A Python dictionary `books_db: Dict[int, Book]` stores books in memory indexed by integer IDs.
   - `_id_counter` maintains state for monotonic, collision-free ID assignment.

4. **Error Handling (`HTTPException`):**
   - Whenever an unknown `book_id` is requested via `GET`, `PUT`, or `DELETE`, FastAPI raises `HTTPException(status_code=404, detail="Book with ID {book_id} not found")`.
   - Schema validation failures automatically trigger FastAPI's built-in `HTTP 422 Unprocessable Entity` response with field-level error messages.

5. **Current Pydantic v2 Syntax:**
   - Uses `payload.model_dump()` to extract validated dictionary representations rather than the deprecated v1 `.dict()`.

## 13. HTTP Status Code Reference Table

| Status Code | Code Name | When Returned by this API |
|---|---|---|
| **200** | `OK` | Successful retrieval (`GET`), update (`PUT`), or deletion (`DELETE`). |
| **201** | `Created` | Successful creation of a new book resource (`POST`). |
| **404** | `Not Found` | When requesting, updating, or deleting a `book_id` that does not exist in `books_db`. |
| **422** | `Unprocessable Entity` | Client input failed schema validation (e.g., missing field, invalid year, empty title). |
